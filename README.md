Project Description
The Student Performance Analytics System is a Python-based project that analyzes student marks and attendance to understand academic performance.

Objective
To calculate student totals, averages, grades, pass/fail status, and attendance status using Python.

Technologies Used
- Python
- Pandas
- NumPy
- CSV
- Google Colab

Dataset
The project uses a sample CSV dataset containing 20 student records, including marks in Python, SQL, HTML, CSS, and JavaScript, along with attendance percentages.

Features
- Calculates total and average marks.
- Assigns grades based on average marks.
- Determines pass/fail status.
- Identifies the highest- and lowest-performing students.
- Calculates class and subject-wise averages.
- Analyzes attendance status.

Results
The project analyzed 20 sample student records and calculated a class average of 80.00. All 20 students passed according to the defined pass criteria.
